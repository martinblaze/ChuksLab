# Horizontal scroll cards with generated art

Vertical scrolling becomes horizontal travel through cards. Each card art (canvas, generated by lib/generators/art.js) drifts against the scroll, with a progress bar and a counter. Below 57em it becomes a swipeable row.

## Files
- `markup.html` — the HTML (copy into a page)
- `style.css` — the component styles (imported by `lib/lib.css`)
- effect code: `Lab.run('hscroll')` in `lib/fx/`
- `demo.html` — standalone preview (serve the ChuksLab folder, open this file)

## Tuning knobs
- Art kinds: cells, tubes, rings, grid, hex, wave (art.js MOTIF)
- Card art parallax: +/-7% xPercent
- Breakpoint: 57em

## Needs
GSAP 3.15 + ScrollTrigger, Lenis, `lib/core/core.js`, `lib/generators/art.js`.
